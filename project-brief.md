# <span style="color:#1e90ff">🌿 ZenName Writer</span>
### <span style="color:#9b59b6">Многоагентная система для генерации статей об именах для Дзен-канала «О чём говорят Славянские Веды»</span>

---

## <span style="color:#1e90ff">🎯 Проблема</span>

Канал постепенно переориентируется на тему имён (история, этимология, помощь родителям и бабушкам/дедушкам в выборе имени). Россия многонациональна, поэтому рассматриваются не только славянские, но и имена разных культур.

**Ключевые проблемы:**

1. <span style="color:#e74c3c">**Масштабирование:**</span> Для удержания аудитории Дзена нужно <span style="color:#f39c12">**5-7 статей в неделю**</span>. Вручную написать одну глубокую, исторически достоверную статью занимает <span style="color:#f39c12">**4-6 часов**</span>.

2. <span style="color:#e74c3c">**Качество:**</span> Текущие статьи не дают нужного охвата. Нейросети без специализированных промптов выдают либо сухие справки в стиле Википедии, либо эзотерику («энергия имени», «кармические задачи»), что противоречит редакционной политике.

3. <span style="color:#e74c3c">**Отсутствие обратной связи:**</span> Нет системного механизма анализа опубликованного контента для постоянного улучшения стиля и структуры будущих генераций.

---

## <span style="color:#1e90ff">👥 Пользователь</span>

- **Основной пользователь:** Автор и редактор канала.
- **Целевая аудитория канала:** Взрослые люди <span style="color:#f39c12">**45-50+**</span>, родители, бабушки и дедушки, интересующиеся историей, культурой и осмысленным выбором имени для ребёнка.
- **Вторичные «пользователи»:** <span style="color:#9b59b6">**9 специализированных ИИ-агентов**</span>, которые взаимодействуют друг с другом через систему промптов.

---

## <span style="color:#1e90ff">⚙️ Основная функция</span>

Сервис выполняет **три ключевые задачи**:

### 1. <span style="color:#2ecc71">Генерация статьи</span>
На вход подаётся имя или тема. На выходе — готовая SEO-оптимизированная статья в формате Markdown (<span style="color:#f39c12">**4000-8000 знаков**</span>), строго соответствующая редакционной политике канала: историческая достоверность, отсутствие эзотерики, специфическая структура, живой и тёплый тон, сенсорные детали.

### 2. <span style="color:#2ecc71">Генерация визуального контента</span>
Агент «Фото-директор» анализирует статью и создаёт промты для нейросетей (Midjourney, Kandinsky, Flux) в <span style="color:#9b59b6">**эстетике Тарковского**</span> — с жёсткими запретами на грязь, обшарпанность и азиатскую внешность.

### 3. <span style="color:#2ecc71">Анализ и обратная связь (Feedback Loop)</span>
На вход подаётся текст опубликованной статьи. ИИ анализирует её и выдаёт конкретные рекомендации по улучшению стиля, структуры или подачи. Эти рекомендации встраиваются в промпты для следующих генераций.

---

## <span style="color:#1e90ff">🏗 Архитектура системы</span>

Проект построен по принципу **многоагентной системы** (Multi-Agent System). Каждый агент имеет узкую специализацию:

| <span style="color:#1e90ff">Агент</span> | <span style="color:#1e90ff">Задача</span> |
|-------|--------|
| <span style="color:#9b59b6">**Стратег канала**</span> | Хранит ДНК проекта: tone of voice, запреты, портрет аудитории |
| <span style="color:#9b59b6">**Автор**</span> | Генерирует первичный черновик с рандомизацией точки входа |
| <span style="color:#9b59b6">**Валидатор**</span> | Проверяет текст на эзотерику, клише и маркеры ИИ |
| <span style="color:#9b59b6">**SEO-специалист**</span> | Подбирает ключевые слова, теги, мета-описание |
| <span style="color:#9b59b6">**Редактор**</span> | Улучшает ритм, убирает повторы |
| <span style="color:#9b59b6">**Фото-директор**</span> | Генерирует промты для изображений |
| <span style="color:#9b59b6">**Трансформер**</span> | Переписывает сухие факты в живую историю |
| <span style="color:#9b59b6">**Оркестратор**</span> | Запускает полный пайплайн за один вызов |
| <span style="color:#9b59b6">**Золотой стандарт**</span> | Генерирует длинные структурированные статьи |

## <span style="color:#1e90ff">📦 Формат результата</span>

1. **Готовый `.md` файл статьи** с:
   - Креативным вступлением через бытовой предмет-якорь (старая тетрадь, фотография, письмо)
   - Чёткой структурой заголовков (H1, H2, H3)
   - Органичным вплетением учёных через действие («Я нашла том Суперанской в библиотеке...»)
   - Концовкой с вопросом к читателю

2. **SEO-метаданные:** ключевые слова, теги, мета-описание для Дзена.

3. **Промты для фото:** 2-3 детальных промта на английском для генерации изображений.

4. **Текстовый отчёт** с рекомендациями по улучшению будущих промптов.

---

## <span style="color:#1e90ff">🛠 Минимальный функционал (MVP)</span>

### <span style="color:#2ecc71">7 режимов работы</span> в консольном интерфейсе:
1. Быстрый автор (генерация черновика за <span style="color:#f39c12">**2-3 минуты**</span>)
2. Оркестратор (полный пакет: статья + SEO + фото-промты)
3. Редактор (анализ и улучшение готового текста)
4. Трансформер (переписка сухого текста в живую историю)
5. Золотой стандарт v2 (длинные статьи <span style="color:#f39c12">**4000+ знаков**</span>)
6. Выход
7. Фото-директор (генерация промтов для изображений)

### <span style="color:#2ecc71">Жёсткие правила в промптах:</span>

<span style="color:#e74c3c">❌ **Запрет:**</span> «энергия», «карма», «родовые программы», «места силы», эзотерика

<span style="color:#2ecc71">✅ **Обязательно:**</span> сенсорные образы, конкретика, бытовой тон, историческая преемственность, учёные через действие

<span style="color:#2ecc71">✅ **Эстетика:**</span> стиль Тарковского, ухоженная винтажность, без грязи и обшарпанности

**Сохранение результатов:** локальная папка `output/demos/` с лучшими примерами.

## <span style="color:#1e90ff">💻 Технологии</span>

- <span style="color:#f39c12">**Python 3.10+**</span> (основной язык логики)
- <span style="color:#f39c12">**Локальная LLM через Ollama**</span> (модель `qwen2.5:14b` — оптимальный баланс качества и скорости для русского языка)
- <span style="color:#f39c12">**Формат данных:**</span> Markdown (.md) для статей, промптов и отчётов
- <span style="color:#f39c12">**Инструмент разработки:**</span> VS Code + Cline (AI-ассистент для вайб-кодинга)
- <span style="color:#f39c12">**Генерация изображений:**</span> Midjourney / Kandinsky / Flux (по промтам от агента)

## <span style="color:#1e90ff"> Планы развития (Roadmap)</span>

1. <span style="color:#9b59b6">**Модуль глубоких исследований (Deep Research & Clustering)**</span>  
   Переход к модели «Хаб и спицы»: один агент генерирует исследование на <span style="color:#f39c12">**10-15 страниц**</span>, второй выделяет <span style="color:#f39c12">**5-10 тем**</span> для статей, третий пишет лонгриды <span style="color:#f39c12">**4000-8000 знаков**</span>.

2. <span style="color:#9b59b6">**Итеративное улучшение промптов (Few-Shot Learning)**</span>  
   Еженедельное добавление лучших статей в `best_examples/` как эталоны стиля.

3. <span style="color:#9b59b6">**Масштабирование базы знаний**</span>  
   При накоплении <span style="color:#f39c12">**50+ статей**</span> система будет генерировать тексты сразу в целевом Tone of Voice.

4. <span style="color:#9b59b6">**Fine-Tuning модели**</span>  
   Дообучение Qwen 2.5 на собственном датасете для «зашивания» стиля канала в веса нейросети.

5. <span style="color:#9b59b6">**Полная автоматизация пайплайна**</span>  
   Интеграция с API Дзена и Telegram для автономного конвейера: исследование → статья → фото → постинг.
