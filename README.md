# 🌿 ZenName Writer — Редакция ИИ-агентов для Дзен-канала

Автоматизированная многоагентная система для генерации душевных, личных историй о славянских именах. Проект создан для канала «О чём говорят Славянские Веды» и использует локальную нейросеть (Ollama + Qwen 2.5:14b) для создания контента, свободного от эзотерики, клише и «воды», с опорой на академические источники и живую бытовую эстетику.

---

## 🎯 Цель проекта
Создать рабочий MVP, который автоматизирует рутину копирайтера: от исследования темы и написания текста до генерации SEO-метаданных и промтов для визуального контента, сохраняя при этом уникальный, тёплый «человеческий» тон повествования.

---

## 🏗 Архитектура системы
Проект построен по принципу многоагентной системы (Multi-Agent System). Каждый агент имеет узкую специализацию и свой промпт в папке `prompts/`:

| Агент | Файл | Задача |
|-------|------|--------|
| **Стратег канала** | `00_channel_strategist.md` | Хранит ДНК проекта: tone of voice, запреты на эзотерику, портрет аудитории. |
| **Автор** | `01_writer.md` | Генерирует первичный черновик с рандомизацией точки входа и сенсорных деталей. |
| **Валидатор** | `02_validator.md` | Проверяет текст на наличие запрещённых клише, эзотерики и маркеров ИИ. |
| **SEO-специалист** | `03_seo.md` | Подбирает ключевые слова, теги и составляет мета-описание. |
| **Редактор** | `04_editor.md` | Улучшает ритм, убирает повторы, делает текст более «живым». |
| **Фото-директор** | `07_photo_director.md` | Анализирует статью и генерирует промты для нейросетей (Midjourney/Kandinsky) в эстетике Тарковского. |
| **Трансформер** | `08_rewriter_simple.md` | Переписывает сухие факты в формат личной истории с диалогами и предметами-якорями. |
| **Оркестратор** | `universal_pipeline.md` | Запускает полный пайплайн: статья + SEO + фото-промты за один вызов. |
| **Золотой стандарт** | `09_gold_standard_v2.md` | Генерирует длинные (4000+ знаков) структурированные статьи с подзаголовками H2. |

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- Установленный и запущенный [Ollama](https://ollama.com)
- Модель `qwen2.5:14b` (или `qwen2.5:7b` для слабых видеокарт)

### Инструкция
1. Установи зависимости:
   ```bash
   pip install -r requirements.txt
2. Скачай модель через терминал:
   ollama pull qwen2.5:14b
3. Запусти главный скрипт: 
   python main.py

  📖 Как пользоваться (7 режимов)
После запуска main.py появится интерактивное меню:
Быстрый автор — генерация черновика за 2-3 минуты.
Оркестратор — полный пакет (статья + SEO + фото-промты).
Редактор — анализ и улучшение готового текста.
Трансформер — переписка сухого фактологического текста в живую историю.
Золотой стандарт v2 — генерация длинной, структурированной статьи с уникальными комбинациями элементов.
Фото-директор — генерация промтов для изображений на основе готовой статьи.

  🚀 Планы развития (Roadmap) 
  Проект построен с расчётом на постоянное улучшение качества через данные (Data-Driven Improvement) и масштабирование контент-стратегии:
Внедрение модуля глубоких исследований (Deep Research & Clustering)
Переход к модели «Хаб и спицы» (Hub and Spoke). Создание отдельного агента для генерации фундаментальных исследований (10–15 страниц) по заданной теме с сохранением в папку research/. На основе этого файла второй агент будет автоматически выделять 5–10 SEO-кластеров (тем для статей), а третий — писать глубокие лонгриды (4000–8000 знаков), опираясь исключительно на факты из исследования.
Итеративное улучшение промптов (Few-Shot Learning)
Еженедельный аудит сгенерированных статей. Лучшие, наиболее «живые» тексты вручную дорабатываются и добавляются в папку best_examples/. Эти образцы затем встраиваются в промпты агентов как эталоны стиля, постепенно снижая необходимость в ручной пост-обработке.
Масштабирование базы знаний
Когда в папке best_examples/ накопится 50+ качественно размеченных статей и исследований, система сможет генерировать тексты, сразу попадающие в целевой тон голоса (Tone of Voice) с первого раза, благодаря мощному контекстному обучению (in-context learning).
Fine-Tuning (Дообучение модели)
Следующий технологический шаг — создание собственного датасета из лучших статей канала и fine-tuning локальной модели (например, Qwen 2.5 или Llama 3). Это позволит «зашить» уникальный стиль канала прямо в веса нейросети, убрав необходимость в длинных системных промптах.
Полная автоматизация пайплайна
Интеграция с API Яндекс Дзена и Telegram для создания полностью автономного конвейера: генерация темы → глубокое исследование → написание лонгрида → валидация → создание изображений → отложенный постинг по расписанию.
